# Foundation review

Separate self-review, not independent platform acceptance. The adapter calls the
actual public EvidenceStore.read_run and preserves accepted records, clocks, IDs
and recorded/assessed statuses. Host source registration pins expected run/plan;
unknown source IDs cannot become paths. Raw schema/record semantics remain Argus's.
Manifest and record bounds, root replacement checks and snapshot-bound cursors are
explicit. Linux secure acquisition is required; unsupported hosts fail actionably.

The adapter is internal only. Raw payload/log exposure still needs host policy;
live source changes invalidate current pagination, so a coherent live snapshot
layer remains required. This component neither authorizes Maestro execution nor
proves that a producer name is native X-COM. Actual runtime provenance and three
linked live views remain open. No task or milestone closes.
