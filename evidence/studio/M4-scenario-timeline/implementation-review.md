## Requirements and resulting behavior

canonical forms and a distinct selected-run inspection. Frozen intentions come from
the verified run snapshot and authoritative full-source validator, never current draft
source. Only the exact installed reference codec admits authored seconds on its own
simulation clock. Other units/clocks, opaque fault schedules and missing source times
remain unplaced. Source and receipt times are independent; original uncertainty stays
visible as source metadata. Screen coordinates use bounded relative values while
original integer ticks remain exact strings/BigInt.

FR-054 separates the frozen reference fault parameter from actual fault-request and
fault-observation events. Configuration intent has no invented authored timestamp or
fake Scenario fault identity. Arbitrary activation/recovery strings remain inert and
cannot grant execution permission. Runtime admission and provider behavior are unchanged.

FR-056/FR-057 inspection includes the frozen typed declarations before evaluation,
window/policy, profile/schema/definition identities and immutable result/evidence pins.
Inspection creates no evaluation job. Actual owned results cover pass, fail, incomplete
coverage yielding indeterminate, and numeric metrics with no assertion verdict. The
backend remains the only evaluator; the browser's declaration guard checks shape and
resource bounds, not semantic validity or executable operators.

The additive Studio endpoint is a feature-layer read projection. It uses the existing
managed snapshot verifier, canonical journal reader and persisted evaluation records;
it does not introduce a platform API, private runtime import or another executable
system definition. Backend processing/output limits and input-bound cursors are explicit.
Recorded gaps, invalid prefixes, source-time quality, declaration availability, input
completeness and display paging do not attest complete assertion coverage.
