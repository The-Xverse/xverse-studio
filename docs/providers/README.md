# Provider responsibilities

Providers are separately installed/admitted integrations, never executable project/profile plugins.
The Studio facade contract is `specs/001-industry-agnostic-studio/contracts/provider-contract.md`.
A descriptor must bind public interface/version, actual implementation identity, native OS/architecture,
operations, authority, state transitions, clocks/uncertainty, limits and canonical evidence scope.

The owned reference provider compiles the immutable contributing XDL again before effects, checks
requested/effective model and plan identity, and starts a fixed Python module with an argv vector.
It accepts bounded declared model parameters; imported project commands and arbitrary executable paths
never reach subprocess. Its native worker journals observations with a hash chain and final digest;
this is reference evidence, not an admitted Argus/CARLA/native-X-COM or physical-device claim.

External integrations must establish effective-input equality before launch; a preset-generating harness
cannot silently ignore an edited parameter. Do not import private runtime internals, infer permits,
operate devices or change companion repositories to bypass a missing integration contract.

Lifecycle/process ownership remains with the admitted runtime/provider. Studio persists intent and
reconciles exact references. Reservations must fence, renew and release actual owned assets; expiry or
unknown authority disables active operations. Browser disconnection cannot become implicit termination
or a new owner. Conformance must run natively on each claimed OS and repeat on the actual provider,
including partial startup, lost acknowledgements, stale capabilities, rejected control and cleanup loss.
