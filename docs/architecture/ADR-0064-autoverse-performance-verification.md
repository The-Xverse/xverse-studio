# ADR-0064 — Native authoring/history measurements and duplicate inspection decoding

Date: 2026-11-04. Status: scoped repair implemented; verification in progress.
Traces: T038, T067; NFR-006/NFR-007/NFR-008/NFR-011; AC-030/AC-031.

Measure the existing declared 200-visible-element/400-connection and 50,000-event/
200-row workloads on copied actual Autoverse inputs. Keep one documented warm-up,
30 measurements and the original 150 ms/3 s/2 s p95 thresholds at both required
viewports. Preserve original reference results and the complete remaining plan.

The model variant retains actual Autoverse resource/profile identities and creates
new inert authoring inputs with supported public validation/compilation. Visible
Elements include standalone placement nodes:197 logical assets plus three such
nodes make200. Four hundred single-destination flows make400 graph connections.
Observers reference the new declared topology. This is an explicit load fixture,
not simulator/model fidelity, two-industry proof or execution admission.

Generate a separate clearly labelled, hash-verified synthetic history journal with
new inert fixture IDs and no process/control capabilities. Reuse the actual frozen
snapshot as provenance, preserve the original93-record journal and never call
preflight/Start or mutate captured evidence. Reuse the exact50,000-record fixture
bytes across verification cohorts. Keep generated fixture metadata distinct from
actual run creation, observed telemetry and provider authority.

Measure project open and matching actual validation response/status presentation,
including displayed200nodes/400edges. Local selection waits for the selected
inspector identity to commit and two animation frames. Retain all raw samples,
partial prefixes, browser heap and separate backend RSS. Passive DOM/resource/click
timestamps diagnose app latency versus driver waiting; they never replace HTTP,
input events or response payloads. All interactions and timing limits remain.

The original 1024px cohort records3534.8ms p95 open/validation; selection48.3ms and
history362.8ms pass. A Results count-badge locator prevented its last1440px history
measurement. The corrected full diagnostic cohort passes but exposes1.35–1.40s
background inspection competing with validation, versus about160ms for a warmed
isolated validation request. Inspection parses every authored resource, then
repeats those large decodes inside the Profile-declaration checker.

Pass only already-classified Profile source documents to that same fresh registry
checker. Decode each large System/Deployment once, retain all Profile conflicts,
unknown extension payloads, unparsed-source diagnostics and execution blocking.
No cache, stale schema authority, compilation substitution, new profile semantics,
industry dispatch or execution capability is introduced. A call-count regression
on the actual large model must fail before the repair; controlled original-profile
variants must preserve the same findings and source bytes afterward. Repeat the
native browser cohort and keep all earlier samples/failures as their own cohorts.

Native Windows, other browser engines, assistive technology, human usability,
continuous producer/control responsiveness, simulator scalability and full milestone
acceptance remain independent. A finite synthetic history benchmark does not pass
the live backpressure/control matrix or T096's combined campaign acceptance.
