## Launch and recovery

After the pinned Linux provisioning/build in `docs/user/getting-started.md`:

```text
.venv/bin/python -I -m xverse_studio.host.launcher --data-dir .studio-local/data --port 8876
```

Open http://127.0.0.1:8876 and read the one-use token locally from
`.studio-local/data/bootstrap.json`. Ctrl+C stops the native backend and requests owned cancellation;
browser closure does not own or terminate runs. Follow `docs/user/recovery.md` for stopped-root full
backup/restore, `docs/user/retention.md` for explicit deletion, and `docs/user/scenario-authoring.md`
for authored intent versus admitted execution. All local implementation artifacts remain on loop10.
